# PBL Disain Web — Website Coffee Shop

Proyek **Project-Based Learning (PBL) Disain Web** untuk merancang website informasi dan katalog menu coffee shop yang responsif.

**Status:** Perencanaan (Minggu 1)  
**Calon mitra:** Coffee Jawara / Jo Kopi — belum ditetapkan  
**Teknologi rencana:** React, JavaScript, Tailwind CSS

## Fitur Utama
- **Beranda:** profil singkat dan produk unggulan.
- **Tentang:** informasi usaha.
- **Produk:** katalog menu dari JSON.
- **Kontak:** informasi kontak dan formulir tervalidasi.
- **Opsional:** rekomendasi menu sesuai preferensi pelanggan.

## Tim (5 Anggota)
| Peran | Tugas |
|---|---|
| Project Lead | Koordinasi proyek dan mitra |
| UI/UX Lead | Riset, wireframe, dan desain |
| Frontend A | Beranda, Tentang, navigasi |
| Frontend B | Produk, Kontak, dan interaksi |
| QA & Dokumentasi | Pengujian dan laporan |

## Tahapan PBL
1. **Minggu 1:** Wawancara owner, pegawai, customer; analisis kebutuhan dan desain.
2. **Minggu 2:** Pengembangan website dan pengujian awal.
3. **Minggu 3:** Perbaikan, deployment, dokumentasi, dan presentasi.
